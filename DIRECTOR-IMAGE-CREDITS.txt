KERALA CELEBRITIES
DIRECTOR IMAGE CREDITS
======================

Purpose
-------
This file records image attribution/licensing information for director
portraits used on KeralaCelebrities.com.

IMPORTANT
---------
Do not assume that an image is free to reuse merely because it appears on
Wikipedia. Wikipedia may display images from Wikimedia Commons or images
under other copyright/fair-use arrangements. Use the individual file page
and its stated license as the authority.

The entries below are the reusable sources verified so far. The remaining
directors are intentionally marked "VERIFY" rather than having a license
guessed.

HOW TO USE THIS FILE
--------------------
1. Put this file in the root of the GitHub repository:
   /DIRECTOR-IMAGE-CREDITS.txt

2. Put all director portraits in:
   /celebrities/images/

3. Make the physical filename exactly match the slug used by
   directors.json, followed by .jpg.

4. Keep the original Wikimedia Commons file-page URL in this file.

5. Do not publish an image marked VERIFY until its individual source page
   and license have been checked.

6. If an image is cropped/resized, record "Changes: cropped/resized" in
   that image's entry.

7. This credits file is documentation; it does not itself grant permission.
   The permission comes from the license/authorization attached to the
   individual source image.
